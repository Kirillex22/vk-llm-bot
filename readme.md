# VK ChatBot Control Panel
------------------------------
VK ChatBot Control Panel — это графический интерфейс (GUI) на базе Tkinter для управления интеллектуальным чат-ботом ВКонтакте. Система интегрирована с Sber GigaChat LLM, что позволяет автоматизировать общение, имитируя естественное поведение пользователя.

## Ключевые возможности

* Интеллектуальная генерация ответов: Использование нейросетевой модели GigaChat для поддержания осмысленного диалога.
* Гибкие режимы работы:
  - DIALOG: Полноценное ведение переписки.
  - REACTION: Автоматическое проставление реакций на входящие сообщения.
* Эмуляция человеческого поведения: Настройка скорости печати (символов в секунду) и вариативных задержек.
* Управление контекстом: Выгрузка дампов сообщений и импорт истории из Telegram (с маппингом имен) для обучения или анализа.
* Многопоточное управление: Независимый запуск и остановка сценариев для отдельных пользователей.

## Установка и конфигурация

1. Развертывание. Клонирование репозитория
```bash
git clone https://github.com/Kirillex22/vk-llm-bot
cd vk-llm-bot
```
2. Установка зависимостей (Рекомендуется использовать виртуальное окружение (venv)):
```bash
pip install -r requirements/dev.txt
```
3. Конфигурация
Отредактируйте файл config.yaml, указав ключи доступа и список целевых пользователей:
```yaml
VK_API_TOKEN: "your_vk_token"
USER_VK_ID: "your_vk_id"
GIGACHAT_API_TOKEN: "your_gigachat_token"
users:
  "11111": "Егор"
  "53445": "Костя"
  "11634520": "Глаша"
```
Примечание: Токен VK API можно получить через сервисы типа vkhost.github.io.

## Эксплуатация
Запуск основного модуля управления:
```bash
python -m src.main
```
Параметры панели управления

| Параметр | Описание |
|---|---|
| Target User | Выбор целевого пользователя из сконфигурированного списка. |
| Dump Size | Глубина истории сообщений для анализа контекста. |
| Delay (sec) | Интервал между проверками новых событий. |
| Chars/sec (Min/Max) | Диапазон скорости набора текста для реалистичной имитации. |
| Penalty Scale | Коэффициент задержки при отсутствии входящих сообщений. |

Функции управления

* 🟢 Execute — инициализация бота с текущими пресетами.
* 🟠 Terminate for person — точечная остановка сессии для выбранного ID.
* 🔴 Terminate for all — экстренное завершение всех активных процессов.
* 💾 Data Ops — инструменты экспорта (VK Dump) и импорта (Telegram Mapping).
